MADAME ADESIVOS — ARQUIVOS CORRIGIDOS

1. Para ver no computador, EXTRAIA o arquivo ZIP inteiro.
2. Abra o index.html de dentro da pasta extraída. NÃO abra apenas o HTML isolado.
3. Para o GitHub Pages, envie o index.html e as pastas imagens e videos para a RAIZ do repositório madameadesivos (não a pasta externa).
4. Espere a publicação e atualize a página (Ctrl+F5).

Atenção: algumas fotos foram associadas por semelhança visual porque o HTML original continha somente códigos temporários do Claude. Confira a correspondência entre foto e produto. Os 5 vídeos estão incluídos em videos; apenas 2 foram vinculados aos produtos que já tinham vídeo no HTML.

A área de edição integrada ao Claude depende da plataforma Claude e não funciona como painel administrativo no GitHub Pages.
